# NFA Independent Study Program – ReactJS Forward

This repository was created as learning material for the NFA Certified Independent Study (SIB) program.

The focus of this repository is practice and experimentation using ReactJS for modern web application development.

This repository is not intended to be a final product, but rather documentation of the learning process and exploration of the material.

## Objectives
- Documenting ReactJS learning outcomes during the NFA Independent SIB program.

- Practicing basic to advanced ReactJS concepts (components, props, state, hooks).

- Maintaining notes for independent experimentation and practice.
